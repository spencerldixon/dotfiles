- Never use em dash. Use plain dash instead
- Never co-author a commit
- Never manually modify CHANGELOG or any files marked as autogenerated
- Search with `rg -n` (or `rg --files`), or your harness's built-in search tool if it has one, then read only the line ranges you need. Avoid dumping whole large files
- Batch independent reads into one command or parallel tool calls
- Bound history: `git log -n 20 --oneline -- <path>`, not an open-ended log
